# NOVA BANK – ATM Management System

A desktop-based ATM Management System developed using Java Swing, JDBC, and MySQL as a B.Tech academic group project at DIT University, Dehradun.

## Project Overview

NOVA BANK is a Java-based ATM application designed to simulate basic banking operations through a graphical user interface.

## Features

- User Login and Authentication
- New Account Creation
- PIN Management
- Balance Inquiry
- Cash Deposit
- Cash Withdrawal
- Transaction History
- MySQL Database Connectivity
- Transaction Data Persistence

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA

## Project Type

Academic Group Project – B.Tech CSE

## Learning Outcomes

- Object-Oriented Programming
- Java GUI Development
- Database Connectivity using JDBC
- SQL and Database Management
- Application Development
